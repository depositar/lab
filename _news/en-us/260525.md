[Data Package][] is a standard to describe datasets and data files, developed by Open Knowledge Foundation. A Data Package is an archive containing a `datapackage.json` descriptor (which uses [JSON Schema][] to describe the dataset) and one or more data resources.

The [depositar][] has added support for Data Packages in the latest [v6.8.0](https://docs.depositar.io/en/stable/changelog.html#v6-8-0-2026-05-20) version, including the following features[^1]:

* * *

### Download the dataset as a Data Package

You can obtain the Data Package for a dataset (the newest edition) from the “Download Data Package” in the upper right corner of the dataset page[^2]:

<div class="row">
    <div class="col-sm-8 mx-auto mt-3 mt-md-0">
        {% include figure.html path="assets/img/news/260525-2_en.png" class="img-fluid rounded" %}
    </div>
</div>

### Import the Data Package as a dataset

You can import Data Packages from external sources (e.g., [GBIF Camera Trap Data][] or [DataHub Core Data][]), and deposit them as datasets:

<div class="row">
    <div class="col-sm-8 mx-auto mt-3 mt-md-0">
        {% include figure.html path="assets/img/news/260525-3_en.png" class="img-fluid rounded" %}
    </div>
</div>

### Automatic Data Package Generation

When a dataset is created or edited, a Data Package will be generated automatically for the dataset[^2].
