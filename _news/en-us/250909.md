The site [stats.depositar.io](https://stats.depositar.io) is a statistics dashboard that visualizes the current status of the depositar, a repository for research data. This website presents various statistical metrics related to the datasets on depositar through interactive charts. The goal is to help both users and administrators of depositar intuitively understand the state of the repository. Statistical data are automatically updated daily at 3:00 AM Taipei time.

This project was [presented](/news/250630_1/) in Open Repositories 2025. The abstract and presentation slideset are available on [depositar](https://pid.depositar.io/ark:37281/k5w9w7145) and [Zenodo](https://doi.org/10.5281/zenodo.15716740).

The following sections introduce the three main pages on the depositar stats page: **Dataset Statistics**, **Dataset Trends**, and **Metadata Completeness**.

## Dataset Statistics

<div class="row">
    <div class="col-sm mt-3 mt-md-0">
        {% include figure.html path="assets/img/news/250909_en_2.jpg" class="img-fluid rounded" %}
    </div>
</div>

This page provides a snapshot of the current status of depositar, updated daily. It features four sections:

* Distribution of Datasets: 
A bar chart shows the distribution of datasets across different metadata fields, along with the median, mean, and mode. For example, under the Tag tab, a chart counts the datasets by the number of tags they have. This allows users to see how many datasets contain a given number of tags.
* Frequency Distribution of Field Values Across Datasets: 
An area chart illustrates how datasets are spread across the values of a given metadata field. In addition, pie and bar charts highlight the top 10 field values with the most datasets. For instance, users can identify the creator with the largest number of datasets, as well as view creators ranked by their dataset counts.
* Top Datasets (By Field Value): 
A summary highlights the most frequently used field value in metadata fields across all datasets. For instance, it identifies the project or creator with the most datasets.
* Daily Statistics: 
A tabular view shows dataset status by date. Users can select a specific date, copy table content to the clipboard, or export the data in various formats.

## Dataset Trends

This page illustrates how depositar’s collections vary over time. Users can select a specific time range to explore, with the default view showing trends across the past year. The page features two sections:

* Total Count Trends: 
An area chart shows changes in dataset statistics over time. For example, it can display the cumulative growth of dataset counts.
* Metadata Field Value Trends: 
A series of line charts illustrate how specific metadata field values change over time. For instance, under the Creator field, the chart shows how the number of datasets contributed by each creator changes across the selected time range.

## Metadata Completeness

<div class="row">
    <div class="col-sm mt-3 mt-md-0">
        {% include figure.html path="assets/img/news/250909_en_4.jpg" class="img-fluid rounded" %}
    </div>
</div>

This page reports the metadata completeness of the datasets in depositar, according to two different levels:

* Dataset-level Metadata Completeness: 
A bar chart shows the metadata completion rate at the dataset level for all deposited datasets.
* Resource-level Metadata Completeness: 
A donut chart represents the metadata completion rate at the resource level for all deposited datasets.
