[Data Package][]（資料封裝包）是一種描述資料集與其所包含資料的標準，由開放知識基金會設計。一個 Data Package 壓縮檔，包含以 [JSON Schema][] 描述資料集後設資料的 `datapackage.json` 描述檔，以及一或多個資料檔案。

[研究資料寄存所][] (depositar) 已於日前（[v6.8.0](https://docs.depositar.io/zh-tw/stable/changelog.html#v6-8-0-2026-05-20) 版本）新增 Data Package 支援，主要功能如下[^1]：

* * *

### 可下載資料集為 Data Package

您可點選資料集頁面右上角「下載 Data Package」按鈕，取得最新版本之 Data Package 壓縮檔[^2]：

<div class="row">
    <div class="col-sm-8 mx-auto mt-3 mt-md-0">
        {% include figure.html path="assets/img/news/260525-2_zh-tw.png" class="img-fluid rounded" %}
    </div>
</div>

### 可匯入 Data Package 為資料集

您可上傳來自其他網站的 Data Package（如 [GBIF 自動相機資料][] 與 [DataHub Core Data][]），並寄存為 depositar 資料集：

<div class="row">
    <div class="col-sm-8 mx-auto mt-3 mt-md-0">
        {% include figure.html path="assets/img/news/260525-3_zh-tw.png" class="img-fluid rounded" %}
    </div>
</div>

### 能自動產製 Data Package

當您建立與編輯資料集，depositar 將自動產製 Data Package[^2]。
